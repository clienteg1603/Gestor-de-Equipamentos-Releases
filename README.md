# Gestor de Equipamentos — Releases

Repositório **público** usado exclusivamente para distribuir atualizações oficiais do Gestor de Equipamentos.

## O que pode aparecer aqui

- Releases oficiais do programa
- `Gestor_Equipamentos_vX.Y.Z.zip`
- `Gestor_Equipamentos_vX.Y.Z.zip.sha256`
- notas de versão

## O que não fica aqui

- código-fonte
- testes
- scripts internos
- chaves privadas
- tokens ou credenciais
- dados de clientes

O código de desenvolvimento é mantido separadamente em repositório privado.
