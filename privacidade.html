Seus dados de trabalho permanecem sob controle da sua instalação.

O Gestor de Equipamentos foi estruturado para funcionar com armazenamento local, sem depender de uma conta em nuvem para manter os registros operacionais do programa.

Dados do programa

Os registros, configurações e demais dados operacionais do Gestor são mantidos na instalação do cliente. Quando o recurso Pro de compartilhamento é utilizado, esses dados podem circular somente pela rede local configurada entre as estações da própria empresa.

Compra e licenciamento

Ao optar pelo pagamento online, os dados necessários para identificar o pedido e emitir a licença — como empresa ou titular, responsável, e-mail, WhatsApp quando informado, plano, período e código do computador — são enviados ao backend seguro do Gestor. O pagamento é processado pelo Mercado Pago em seu próprio checkout.

Dados de cartão, conta bancária e demais credenciais financeiras são informados diretamente ao Mercado Pago e não são armazenados pelo Gestor. O backend registra os identificadores e estados necessários para conferir o pagamento e impedir a liberação de uma licença para um pedido divergente.

Os registros operacionais criados dentro do Gestor não são enviados ao Mercado Pago durante uma compra.

Atualizações

O programa pode acessar a internet para consultar e baixar novas versões oficiais. O conteúdo distribuído publicamente contém apenas os arquivos necessários para atualização e as notas de versão.

Este site

O site não exige cadastro para navegar ou baixar o programa. Para identificar a versão mais recente, a página consulta a publicação oficial de versões do Gestor. A página de compra só usa o backend de pagamento quando o cliente escolhe iniciar uma compra online.

Backup

Como os dados de trabalho ficam sob responsabilidade da instalação do cliente, mantenha cópias de segurança adequadas ao seu ambiente e à importância das informações registradas.
