Seus dados de trabalho permanecem no seu computador.

O Gestor de Equipamentos foi estruturado para funcionar com armazenamento local, sem depender de uma conta em nuvem para manter os registros do programa.

Dados do programa

Os registros, configurações e demais dados operacionais do Gestor são mantidos localmente no computador em que o programa é utilizado.

Atualizações

O programa pode acessar a internet para consultar e baixar novas versões oficiais. O conteúdo distribuído publicamente contém apenas os arquivos necessários para atualização e as notas de versão.

Este site

O site não exige cadastro para navegar ou baixar o programa. Para identificar a versão mais recente, a página consulta a publicação oficial de versões do Gestor.

Backup

Como os dados de trabalho ficam no computador, mantenha cópias de segurança adequadas ao seu ambiente e à importância das informações registradas.
